교산에서 자주 묶여 언급되는 두 블록인데 상태가 전혀 다릅니다.

**S1은 사업자가 정해졌고 착공이 2027년 12월입니다. A5는 사전청약을 3년 전에 끝냈는데 본청약 공고가 없습니다.**

## S1 — DL이앤씨 컨소시엄으로 정해졌습니다

먼저 짚을 것이 있습니다. **S1은 LH 사업이 아니라 GH(경기주택도시공사) 사업입니다.**

교산 공동사업시행자 지분이 이렇게 나뉘어 있습니다.

| 시행자 | 지분 |
| --- | --- |
| LH | 65% |
| **GH (경기주택도시공사)** | **30%** |
| 하남도시공사 | 5% |

S1이 GH 몫에서 나온 블록입니다. 민간참여 공공주택이라 민간사업자가 설계·시공·분양 전 과정에 들어옵니다.

### 우선협상대상자 — 2025년 12월 17일 선정

| 역할 | 건설사 |
| --- | --- |
| 주관 | **디엘이앤씨** |
| 참여 | 태영건설 · 금호건설 · 케이알산업 · 신동아종합건설 |

GH가 **재공모 결과**로 선정했습니다. 1차 공모는 유찰됐습니다.

```
2025.10.16   1차 공모 공고
2025.11.06   확약서 마감 — DL이앤씨 컨소시엄 단독
2025.11.07   재공모 공고
2025.12.08   재공모 신청서 마감
2025.12.17   우선협상대상자 선정 — GH 공고 제2025-0719호
```

선정일은 GH 공고문 원문의 *"우선협상대상자 선정일 : 2025.12.17.(수)"* 를 따랐습니다. 지역 매체 보도는 해를 넘겨 2026년 1월 5일에 나왔습니다.

**단독 응찰이라 경쟁이 성립하지 않아 유찰됐고, 다음날 재공모에 들어갔습니다.** 재공모에서 같은 컨소시엄이 우선협상권을 가져갔습니다. 최종 컨소시엄에는 케이알산업이 추가돼 5개사가 됐습니다.

### 규모 — 교산에서 드문 중형 비중

| 항목 | 내용 |
| --- | --- |
| 총 세대수 | **705가구** 공공분양 |
| 60㎡ 이하 | 282가구 |
| **60\~85㎡** | **426가구** |
| 최고층 | 29층 |
| 총사업비 | 5,737억원 (GH 3,220억 + 민간 2,316억) |

**60\~85㎡가 426가구로 전체의 60%입니다.** 교산 아파트는 60㎡ 이하가 54.5%로 소형 위주인데, S1은 반대입니다. 중형 면적대를 교산 공공분양에서 찾는다면 현재까지 가장 유력한 블록입니다.

최고 29층은 인근 원도심 평균이 20층 안팎이라 스카이라인 급변은 없다고 평가됐습니다. 층간소음 저감 기술과 친환경·스마트 주거 기술 적용이 예고됐습니다.

### 일정

| 단계 | 시기 |
| --- | --- |
| 사업계획 승인 | **2026년 내** 완료 목표 (보도) |
| **착공** | **2027년 12월** — 공모지침서 제4조 |
| **준공** | **최대 2030년 11월** — 착공 후 35개월 이내 |
| 분양 | **지침서에 없습니다** |
| 입주 | 2031년 (선정 후 보도) |

**착공과 준공은 공모지침서 제4조에 적힌 숫자이고, 분양 시기는 그 문서에 없습니다.** 지침서는 착공 시점에도 단서를 달았습니다 — *"공모일 기준 착공 시점은 '27년 12월이나, 원도심 기반 시설 사용을 위한 하남시 협의 결과 등에 따라 착공 시점은 조정될 수 있"* 다고요.

그리고 사업기간은 **협약체결일부터** 셉니다. 사업협약 체결은 아직 확인되지 않았습니다. 시계가 시작되지 않은 일정입니다.

선정 후 보도에 나온 "2027년 하반기 착공, 2031년 입주"는 지침서의 "'27년 12월 착공, 최대 '30년 11월 준공"과 어긋납니다. 이 글은 지침서 쪽을 1차 출처로 봤습니다.

### 자료끼리 엇갈리는 숫자

| 항목 | 공모지침서 (2025.10 · 11) | 선정 후 보도 (2026.01) |
| --- | --- | --- |
| 60\~85㎡ | 423가구 | **426가구** |
| 민간 투자 | 2,517억 (공사비·기타비용) | **2,316억** |
| 컨소시엄 | 4사 | **5사** |

705가구 총계와 60㎡ 이하 282가구는 양쪽이 같습니다. 민간 분담액은 산정 범위가 달라 보이는데 확인하지 못했습니다.

## A5 — 나눔형, 사전청약만 끝난 상태

| 항목 | 내용 |
| --- | --- |
| 총 세대수 | 492가구 |
| **사전청약 물량** | **452가구** |
| 유형 | 뉴:홈 **나눔형** |
| 사전청약 | **2023년 10월** |
| 추정 분양가 (59㎡) | **4억 5,000만원 선** |
| 입주 예정 | 2030년 1월 |

사전청약 452가구의 면적 구성입니다. 국토교통부 사업계획 승인 자료 기준입니다.

| 전용 | 세대수 |
| --- | --- |
| 46㎡ | 10 |
| 55㎡ | 56 |
| **59㎡** | **386** |

**59㎡가 386가구로 85%입니다.** 소형 단일 구성에 가깝습니다.

**사업계획 승인은 났는데 본청약 공고가 없습니다.** [10월 26일 하남시 브리핑](/blog/2026-10-28-gyosan-supply-delay)의 *"A2블록을 제외하면 주택 공급 공고가 이뤄지지 않았다"* 가 이 블록을 포함합니다. 사전청약으로부터 3년이 지났습니다.

### 나눔형은 조건이 붙습니다

분양가가 싼 대신 처분이 묶입니다.

- 주변 시세의 **70% 이하**로 분양가 책정
- **5년 의무거주**
- 처분할 때 **반드시 LH에 환매**
- 처분 손익의 **30%를 국가에 반납**

**상승기에 민간 아파트만큼의 시세차익은 안 나옵니다.** 반대로 하락기에는 손실의 30%도 LH가 분담합니다. 자산 증식보다 주거 안정을 우선하는 구조입니다.

## A2 전례로 A5를 읽으면

교산에서 본청약까지 간 블록은 A2 하나뿐입니다. 그 전례가 A5를 예측하는 유일한 재료입니다.

### A2에서 실제로 일어난 일

| 항목 | 사전청약 당시 | 실제 |
| --- | --- | --- |
| 본청약 | 2024년 9월 예정 | **2025년 4월** (7개월 지연) |
| 입주 | 2027년 3월 | **2029년 6월** (2년 3개월 지연) |
| 59㎡ 분양가 | 4억 8,695만원 | **약 5억 7,000만원** |

**분양가가 17% 올랐습니다.** 8,500만원입니다. 다른 주택형도 사전청약 추정가보다 16\~18% 높아졌습니다.

### A5 본청약 분양가를 역산하면

A5의 추정 분양가 4억 5,000만원에 A2의 상승률을 그대로 대입한 값입니다.

| 상승률 | 59㎡ 예상 분양가 |
| --- | --- |
| +16% | 5억 2,200만원 |
| +18% | 5억 3,100만원 |

**5억 2,000만\~5억 3,000만원대입니다.** 제 계산이고 공식 자료가 아닙니다. 다만 A2가 유일한 전례이고 그 폭이 16\~18%로 좁게 모여 있어, 4억 5,000만원을 그대로 믿기는 어렵습니다.

### 당첨자는 얼마나 남는가

| 구간 | 수치 |
| --- | --- |
| 교산 전체 사전청약 당첨자 | 1,508명 |
| 당첨 취소·포기 | **308명 (20.4%)** |
| A2 사전청약 당첨자 | 866명 |
| A2 본청약 신청 | **728명 (84.1%)** |

빠져나간 138가구는 **일반공급 물량으로 전환**됐습니다. A5에서도 같은 일이 일어나면 452가구 중 일부가 일반 물량으로 돌아옵니다.

다른 3기 신도시와 비교하면 교산의 신청률이 높은 편입니다.

| 지구 | 본청약 신청률 |
| --- | --- |
| **하남교산 A2** | **84.1%** |
| 고양창릉 3개 블록 | 73% |
| 인천계양 A2 | 55% |

교산은 분양가가 17% 올랐는데도 84%가 따라왔습니다. 입지에 대한 평가가 그만큼이라는 뜻으로 읽힙니다.

## A5의 미결 쟁점 — 전용 모기지

A5에서 면적이나 분양가보다 먼저 확인해야 할 대목입니다.

사전청약 당시 안내된 조건입니다.

| 항목 | 안내 내용 |
| --- | --- |
| LTV | 80% |
| 한도 | 5억원 |
| 금리 | **연 1.9\~3.0% 고정** |
| 만기 | **최장 40년** |
| DSR | 미적용 |

이 조건이 2026년에 흔들렸습니다.

```
2026.07.02   고양창릉 S3 본청약 공고 — 전용모기지 대신 디딤돌,
             한도 4억으로 1억 축소  →  당첨자 반발
2026.07.07   국토부: 5억·LTV 80%·DSR 미적용은 유지.
             단 금리·만기는 "신청 시점 디딤돌 요건 적용"
2026.08.07   하남시의원 3명, A5 원안 이행 건의안 국회 전달
2026.08.25   김윤덕 장관 간담회 → 요구 수용.
             40년 만기 · 1.9~3.0% 고정금리 적용
```

**그런데 8월 25일 결정의 적용 범위가 애매합니다.**

보도된 문구는 *"현재까지 입주자 모집을 마친 모든 세대"* 입니다. **A5는 입주자 모집을 아직 하지 않았습니다.**

반대로 7월 7일 발표에는 *"앞으로 공급하는 나눔형·선택형 입주자 모집공고에도 전용모기지와 중도금 집단대출을 명시"* 가 있어 A5가 포함되는 쪽으로 읽힙니다.

**두 문구가 엇갈립니다.** A5가 1.9\~3.0%·40년을 받는지 확정된 자료를 찾지 못했습니다. 본청약 공고문에 적힐 내용이고, 그 공고가 아직 없습니다.

4억 5,000만원이 5억 2,000만원대로 오르는 것과 금리가 1.9%에서 디딤돌 수준으로 오르는 것이 겹치면, 사전청약 당시의 자금 계획은 다시 짜야 합니다.

## 정리

| | S1 | A5 |
| --- | --- | --- |
| 시행 | **GH** | LH |
| 유형 | 민간참여 공공분양 | 뉴:홈 **나눔형** |
| 규모 | 705가구 | 492 (사전청약 452) |
| 면적 | **60\~85㎡ 426가구** | **59㎡ 386가구** |
| 사업자 | **DL이앤씨 컨소시엄 (확정)** | LH 직접 |
| 분양 | 2027년 | **공고 없음** |
| 입주 | 2031년 | 2030년 1월 (예정) |

**S1은 신규 청약을 노릴 수 있는 블록입니다.** 2027년 분양이고 중형이 426가구입니다.

**A5는 신규 청약 대상이 아닙니다.** 452가구가 이미 사전청약 당첨자 몫입니다. 포기분이 일반공급으로 전환되는 물량만 변수인데, 그것도 본청약 공고에 달려 있습니다.

## 공개되지 않은 것

| 항목 | 상태 |
| --- | --- |
| S1 사업협약 체결 여부 | 선정 이후 보도 없음 |
| S1 분양 시기 (월 단위) | **공개 없음** |
| A5 본청약 공고일 | **공개 없음** |
| A5 전용모기지 최종 적용 | **7월·8월 발표가 엇갈림** |
| S1 1차 공모 유찰 사유 | 공개 없음 |

## 한계

**A5 본청약 분양가 5억 2,000만\~5억 3,000만원은 제 계산입니다.** A2의 상승률 16\~18%를 A5 추정가에 대입한 값이고, 공식 자료가 아닙니다. A2는 일반형이고 A5는 나눔형이라 가격 결정 구조가 다를 수 있습니다.

**A5 추정 분양가 4억 5,000만원도 확정가가 아닙니다.** 2026년 7월 보도 기준이고, 본청약 공고에서 바뀝니다.

**S1 선정은 우선협상대상자 단계입니다.** 사업협약 체결과 사업계획 승인이 남아 있습니다. 선정 이후 진행 상황은 보도가 확인되지 않았습니다.

**사전청약 제도는 2024년 폐지됐습니다.** 본청약 지연과 분양가 상승이 이유로 꼽혔습니다. A5는 그 제도의 마지막 물량에 해당합니다.

**교산 총 공급 규모는 자료마다 다릅니다.** 이번에 본 기사는 33,647가구로 적고 있는데, [9월 글](/blog/2026-09-08-gyosan-new-town)에서 확인한 로드맵은 36,697가구였습니다. 계속 어긋나는 항목입니다.
